# 个人智能训练工作台

这是一个本地电脑端 MVP，用来替代教练用 Excel 管理训练计划，并逐步补上动作级反馈、饮食自然语言记录、身体指标追踪和智能建议。

完整产品目标、边界、阶段设计和验收标准见：[docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md)

## 运行方式

直接双击打开 `index.html` 即可使用。

当前版本是零依赖静态应用，数据保存在浏览器本地存储中。建议在“导入导出”页定期导出 JSON 备份。

## 当前状态

- 阶段 0：本地工作台 MVP，已完成。
- 阶段 1：动作级训练反馈，已完整完成，支持动作历史回看和长期画像。
- 阶段 2：饮食自然语言记录，已完整完成，支持餐次拆分、食物项识别、营养估算、趋势展示和长期画像。
- 阶段 3：画像与联动基础，已完成基础版，支持动作长期画像、饮食长期画像和首页联动建议。

## 已有功能

- 目标设定
- 健身房/场地器械管理
- 动作库、器械图例和肌肉示意图
- 动作页 Wikimedia Commons 开放许可预览图
- 按当前器械范围生成替代动作
- 身体指标记录和趋势图
- 训练计划生成
- 训练日整体反馈
- 动作级训练反馈
- 动作反馈历史回看
- 饮食自然语言记录
- 饮食营养估算和趋势图
- 动作长期画像和饮食长期画像
- 基础智能建议
- 计划 CSV 导入/导出
- 全量 JSON 备份/恢复
