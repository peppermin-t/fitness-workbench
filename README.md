# 个人智能训练工作台

这是一个本地电脑端 MVP，用来替代教练 Excel 管理训练计划，并逐步增加动作级反馈、饮食自然语言记录和智能建议。

完整产品目标、边界、阶段设计和验收标准见：[docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md)。

## 运行方式

直接双击打开 `index.html` 即可使用。

当前版本是零依赖静态应用，数据保存在浏览器本地存储中。建议在“导入导出”页定期导出 JSON 备份。

## 当前状态

- 阶段 0：本地工作台 MVP，已完成。
- 阶段 1：动作级训练反馈，已加入基础入口和本地标签建议。
- 阶段 2：饮食自然语言记录，已加入基础入口和本地结构判断。
- 阶段 3：画像与联动基础，已加入动作长期画像、饮食长期画像和首页联动建议。

## 已有功能

- 目标设定
- 健身房/场地器械管理
- 动作库和示例链接
- 按当前器械范围生成替代动作
- 身体指标记录和趋势图
- 训练计划生成
- 训练日整体反馈
- 动作级训练反馈
- 饮食自然语言记录
- 基础智能建议
- 计划 CSV 导入/导出
- 全量 JSON 备份/恢复
